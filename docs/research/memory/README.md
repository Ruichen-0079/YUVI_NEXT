## 一页结论

**V1 留下了什么：**

- 成熟的存取工程：来源纪律与逐字引文、可重建的派生索引、中文词项与语义的混合召回及其失败模式、有界的模型任务生命周期、冷恢复与 UNKNOWN。
- 一套很好的理论：生活实感、时间印象、人格惯性、测量先于变量。

**V1 缺了什么：**

- 记忆的动力学从未运行；
- 记忆的对象是用户，不是它自己；
- 多个存储各自持有部分真相，没有一个统一的过程；
- 一部分产物从未到达模型；
- 程序在不同阶段以规则或固化的“当前知识”替它定义主观认知。

**V2 现在缺什么（P1–P4 之上）：**

- 随规模可用的档案存取；
- 中文可用、能排序的检索；
- 它自己的回忆工具；
- 记忆是否到达模型的记录；
- 任何让记忆在经历中重新组织的机制；
- 检验这些的评测台。

**建议的架构：** 一个统一的个体记忆过程。

- **档案（只追加）**同时承载经历、它写下的文字、它的存取行为，以及每次请求实际呈现了什么。
- **派生索引**放在独立文件，可整体重建。
- **一个组装处**是记忆进入模型的唯一通道：前景、原文窗口与线索浮现。
- **它自己的重整**让旧文字被重新理解。
- **按访问历史的激活**决定什么更容易被想起。这是研究假设，可开关、可消融。

核心理由：把 V1 混在一起的四类东西分开——程序拥有可核验的边界与可重建的索引，它拥有自己的记忆。

**路线：**

1. 三个基础：档案存取增量化 → 统一组装与呈现记录、派生索引与查档升级；
2. 并行的合成长期生活评测台；
3. 回忆与浮现 → 重整与激活；
4. 语义向量视评测结果而定。

身体、QQ、主动生活与 `main` 的真实生活放在记忆过程通过评测之后。Alice 切换与 V1 导入删除。
