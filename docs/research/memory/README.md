## 一页结论

**V1 留下了什么：**

- 成熟的存取工程：来源纪律与逐字引文、可重建的派生索引、中文词项与语义的混合召回及其失败模式、有界的模型任务生命周期、冷恢复与 UNKNOWN。
- 一套很好的理论：生活实感、时间印象、人格惯性、测量先于变量。

**V1 缺了什么：**

- 记忆的动力学从未运行；
- 记忆的对象是用户，不是它自己；
- 多个存储各自持有部分真相，没有一个统一的过程；
- 一部分产物从未到达模型；
- 程序在不同阶段以规则或固化的“当前知识”替它定义主观认知。

**架构：** 一个统一的个体记忆过程。

- 只追加档案承载经历、它写下的文字、它的存取行为，以及每次请求实际呈现了什么。
- 派生索引放在独立文件，可整体重建。
- 一个组装处是记忆进入模型的唯一通道。
- 它自己重整旧文字。
- 按访问历史的激活决定什么更容易被想起，作为可开关的研究机制。

**选型：**

- 这一阶段需要的成熟组件已经在 Node 运行时里：SQLite（FTS5、JSON、`VACUUM INTO`）、ICU、`node:test` 的模拟时钟。
- 中文检索用 FTS5 建索引，在应用侧做“汉字单字 + 二元组”切分，不自写倒排。
- 语义向量需要时用本地嵌入进程 + 进程内暴力计算。
- 激活直接采用 ACT-R 公式。
- 不引入任务框架与评测平台。
