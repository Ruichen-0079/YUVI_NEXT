**贯穿始终、经受住多次改写的命题：**

1. 助手自己的生成不能成为关于世界或自己的权威证据（PR #9，08-11 起）。
2. 记录发生了什么，与解释它意味着什么，必须分开。
3. 沉默和不行动是合法的输出。
4. 身份不随模型更换而改变。
5. 时间是真实的：发生时间与记录时间分离，长间隔不被压成“刚才”。

## 4. 重要的方向改变及原因

| 改变 | 原因 | 结果 |
| --- | --- | --- |
| 关闭 Mem0 推理（08-11，PR #9） | “记忆存储发生过什么的证据，不权威地改写关系、情绪、人格” | 正确的原则；但 Mem0 从此只是带 Python 进程的向量库 |

## 5. 从 V1 走向 V2 的转折

V2 蓝图（YUVI PR #339 §1.2）把 V1 的根本问题归结为一句话：**把研究对象的性质逐一换成了易记录、易验证的显式表示。**

- 心境 → 带时间的文字评价；
- 回忆 → 准确检索；
- 欲望 → 带期限的心意；
- 自主活动 → 有预算的后台任务；
- 个体 → “生活文件 + 模型继承”。

这些工程各自合理，合在一起造出的是一个高度可靠的长期 Agent，而不是研究对象。

具体证据：

- 记忆对象是用户，不是它自己；
- 研究性机制从未开始；
- 地基工程不断推迟研究；
- 合同层没有消费者；
- 治理语言（authority、frozen、fail-closed）成为思维语言。

V2 的回应：

- 新仓库，新个体（不继承 Alice 的生活，不导入 V1 历史，见 V2 [ROADMAP §1、§7](../../ROADMAP.md)）；
- 只追加档案与它自己的记忆分开；
- 程序只处理可核验的关系，不做语义标注；
- 成熟组件优先，领域机制自主；
- 先建成能被检验的记忆过程。

V1 的研究资产以本归档与 [`docs/research/memory/`](../../research/memory/README.md) 的形式进入 V2。V1 的代码、架构与生活历史不直接继承。
