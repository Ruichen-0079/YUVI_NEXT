# P7 实施说明

context.ts 统一对话、整理与工具续步；保留 P6 的有界选择，组装一次产生 messages、请求参数、来源清单与 SHA-256。续步冻结第 0 步基础消息，只追加 assistant/tool，独立记录 now/previous。server 不再拼消息，每次 streamModel 前提交 presented；组装/写入失败按存储故障终止。schema、依赖、P6 数字状态与选择规则均未改。

运行时时间文字使用 P6 原生 Date；候选时区名必须在当前时刻、本年 1 月与 7 月的呈现都与原生 Date 一致，才作为重建前提记录，否则显式记 null；避免 POSIX GMT±N 被 Intl 解释为反向偏移。重建从 previous 链取第 0 步时间；缺失/无效时区报告 time_zone_unrecorded。人设、Node、规则各有独立状态。仅摘要不符且当前 heard 含 U+FFFD 时报告 source_lossy：只是可能有损，不证明损失、不排除实现缺陷。真实 U+FFFD/NUL/emoji 仍须 exact；Node 22 当前回合指示取完整 UTF-8 字节，窗口保持 P6 的解码语义。

presented.ts 的 summary/writings 只读事务扫描与范围计数不取得服务锁；show 只承诺 messages 重建，不冒充完整历史 HTTP 请求。逻辑只读允许 SQLite 维护 WAL/SHM；测试严格检查事件、主库、空闲 WAL 与锁字节/mtime，并覆盖生成期间、关闭后和随后继续对话。
