# P9 百万事件性能

2026-11-04，本机 Linux、Intel Core Ultra 9 275HX（24 个逻辑 CPU）、Node 22.22.0。真实服务入口与回环假模型，外部网络隔离；各项性能测量没有并行运行其他基准。与 Claude 的 4 vCPU/2.8 GHz 验收环境不同，不能把本机通过代称为其机器已通过。

## P1–P4

每种形态 1,000,000 个事件；`writings` 有 24,412 段文字，其中 24,409 段为当前范围内非空文字。候选线索既含 W 查询，也从实际合成来话中抽样。单项预热一次、计时 20 次；原始样本、查询计划、各线索结果、RSS、启动与空闲 health 均在 [million.json](p9-evidence/2026-11-04/million.json)。

| 形态/策略 | 浮现选择 p50 / p95 / 最大（ms） | 回合程序 p95（ms） |
| --- | --- | ---: |
| writings / relevance | 19.03 / 23.09 / 60.08 | 67.62 |
| writings / recency | 1.09 / 4.23 / 7.25 | 4.45 |
| varied / relevance | 33.07 / 41.85 / 47.65 | 4.89 |
| varied / recency | 30.66 / 40.18 / 41.73 | 17.78 |

选择耗时与完整回合是不同采样集合，不能相减推算其余开销。回合统计按 HTTP 两端单调时钟，扣除回环模型驻留时间；包含上下文与呈现记录。p95 门槛全部通过，最大值如实保留。

W1/W2/W8 索引查询 p95 分别为 0.190/0.137/0.127 ms；W5/W7/W9/W10 均不超过 0.429 ms。无查询词最近列表另计为 79.38 ms，不混入罕见词门槛。W6 扫描线程 p95 为 268.81 ms，与同机原扫描只扫 wrote 的比值为 0.994；总数、返回集合一致。未把扫描结果作为索引低延迟结果报告。

writings 档案/索引分别为 419,172,352 / 496,263,168 字节；varied 为 339,525,632 / 320,978,944 字节。writings 的服务 RSS 约 169–173 MiB。两者从空建立索引分别为 164.45 和 39.47 秒。

## P5：默认 recall 开、浮现关，保留 P8 门槛

在全新百万 varied 上重跑 P8 性能驱动（`--p9 1` 只省略无门槛的 typical 及无须比较的逐字扫描；保留全部索引查询和 R17 的扫描比较）。原始 [结果](p9-evidence/2026-11-04/p8-default-million.json) 中 `service.p8` 是本次 P9 默认运行时，`service.p7` 是历史提交 `3343efa`。

- 从空重建含 optimize：53.74 秒。
- 整个在线重建每 100 ms 探测 health：p99 1.28 ms；20 个回合正常，5 次 check 均为 `scan/index_building`，重建后校验成功。
- 全部走索引的 R 查询满足各自 20/200 ms 门槛。R17 扫描 p95/原扫描为 1.010，总数与集合相同。
- 默认配置普通回合程序 p95 4.32 ms；P7 为 4.87 ms。仅报告本次差值，不据此宣称性能改善。增量追平最大 32.91 ms。
- 带完好索引的启动比 P7 增加 872.11 ms（门槛 1 秒）。
- 索引/档案约 0.945，小于 1.5；结构、字符与词元计数均保留在原始结果。

## 复现

```sh
npm run build
unshare -rn sh -c 'ip link set lo up; node scripts/p9/benchmark.mjs /tmp/p9-million'
unshare -rn sh -c 'ip link set lo up; node scripts/p8/benchmark.mjs /tmp/p9-p8-default --p9 1 --recall 1'
```

使用独立新目录，固定 Node 22.22.0，避免并行重负载。全部样本来自离线假模型，不能作为真实模型费用、响应质量或记忆使用的证据。

末次范围核对补充：对未被结果预算选中的 rank 引用，也以一次最多100个 seq 的查询核对来源范围，防止损坏索引经 rank_seqs 暴露外场景引用。随后使用保留的百万合成档案，重新测量全部11个 W 与30个 R 查询：[原始复测](p9-evidence/2026-11-04/scope-query-retest.json)。各自正式门槛仍通过；W6 与 R17 扫描比值分别为0.988、1.027。复测时另有合成生活生成和只读审计在运行，未合并初测与复测样本；普通回合的浮现路径未改。
