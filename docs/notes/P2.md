# P2 实施说明

- 保留 P1 的事件表与单回合串行生成，无新增运行时依赖或持久化表。新终结事件只有已登记的 act/silent；恢复将其视为已结束，不修改旧事件。
- 每次提供 stay_silent、tool_choice=auto、stream_options.include_usage=true；不加沉默时机的提示词。按 tool_calls 的 index 拼接函数名与 JSON 参数片段。完整流无文本且恰有一个合法 stay_silent 时记 silent，reason 缺省为空；有文本时以 said 结束，工具名记 ignored_tools。正常空流仍按 P1 记空 said。无文本的未知工具、多次调用或非法参数记模型失败，不猜测选择；有文本时不执行/验证工具参数。没有多步工具循环。
- 上下文按 seq 原序选取最近 heard/said/silent，用仅含 id、seq、作者、时间、reply_to 的前缀标识来源，后接未改写原文，作者角色为 user/assistant；silent 用 user 角色的档案关系记录表示“该 heard 没有回复”，不把理由冒充对外消息。最后追加 user 回合指示，包含当前 heard 的 id、seq、作者、时间和原文，不写入档案。排队中的 heard 也按实际顺序保留。
- 空闲上限默认 60000 ms，总时长上限默认 600000 ms；两个新环境变量须为 1–2147483647 的整数毫秒。收到响应头和每个非空字节块（含注释、工具、usage）重置空闲计时，总时长计时不重置。超时沿用 P1 not_sent/partial，不自动重试。
- usage 对象原样保存到终结事件；即使之后断流，只要已收到 usage 就保留。未收到或进程中断恢复不估算。/api/usage 直接从档案按终结事件的 UTC 日期重算；额外数值字段相加，嵌套数值按原层级相加，字符串/数组不求和。date/turns/turns_with_usage 为接口保留字段，不从提供方字段覆盖。P1 旧终结事件计 turns，不计 turns_with_usage。
- 启动时只展示程序生成、仅含变量名的配置错误，不直接输出任意异常。数据库失败指出 YUVI_DATA_DIR，监听失败指出 YUVI_HOST/YUVI_PORT，不含值。实测使用回环假服务与真实子进程（含 40 秒流、重启、超时和用量），浏览器检查可用 YUVI_CHROMIUM 启用；真实 DeepSeek 由负责人检查。
- 未改变范围或验收契约；以上异常工具处理及嵌套用量呈现是规格未限定的局部选择。未改受保护文档，未增加 P3、记忆、主动行为、金额计算或其他工具。
